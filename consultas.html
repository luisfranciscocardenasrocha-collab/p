PRUEBA CONSULTAS

Para obtener una consulta en MySQL es importante reconocer los datos guardados y reencontar los usuarios que entan dentro de las tablas

SELECT * FROM 'usuario';

dicha etiqueta muestra la razon optima de obtener una consulta ,a este pequeño codigo se le conoce como la base para seguir con mas consultas ya escritas en la tabla utilizando (WHERE) para asi pedir una consulta ya hechay anexada en la tabla seleccionandolo por un "id".

sintaxis

SELECT * FROM 'usuario' WHERE id="2";
